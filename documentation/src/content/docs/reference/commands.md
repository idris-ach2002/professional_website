## Maven

```bash
./mvnw test
./mvnw clean verify
./mvnw spring-boot:run
```

## Docker

```bash
docker compose up --build
docker compose down
```

## Documentation

```bash
cd documentation
npm install
npm run check
npm run dev
npm run build
```
